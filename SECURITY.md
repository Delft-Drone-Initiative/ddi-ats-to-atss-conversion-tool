# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not report security problems in public issues or discussions.

Report them privately through GitHub: go to the **Security** tab of this
repository and click **Report a vulnerability**.

Please include the affected version, a description of the problem and,
if possible, the steps to reproduce it.

We will reply as soon as we can and keep you informed while we work on a
fix. Please give us reasonable time to release a fix before disclosing the
problem publicly.
